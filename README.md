## 每周固定流程（每门课）

1. **课前**：把本周课件发给我 → 我给你中文讲解 + 术语表 + 3 个可以在 tutorial 上说的英文句子
2. **听录播课**（1 小时）：看不懂的地方记下时间点
3. **Tutorial 后 10 分钟内**：用中文记下“今天讨论了哪个案例、我们组怎么分析的、我说了什么、结论是什么”——这是学习日志和个人报告反思部分的原材料
4. **周末**：把笔记发给我，我帮你整理成英文要点，并标出和作业的关联
