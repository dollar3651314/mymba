# ✍️ 期末 Quiz 准备区：BUSI 1772 个人测验（占 40%）

## 📌 先做这件事：补做第 1–5 周的自测 quiz
期末 15 道题里，**有一部分直接从每周自测题里随机抽**。所以每周自测做过、错题弄懂，就等于提前见过考题。

### 在哪里找
1. 打开 **Moodle**（不是 Canvas）→ 进入 BUSI 1772 课程页。
2. 找到每周的文件夹（Week 1、Week 2……），里面在录播课（Panopto）和阅读材料旁边，有一个名字类似 **“Quiz 1”“Quiz 3 - Efficient Markets”** 的测验。
3. 点进去 → **Attempt quiz**（开始答题）。每次约 **10 分钟**，交卷后马上显示对错。
4. 找不到的话：在 Moodle 课程页用 Ctrl+F 搜 “Quiz”，或者截图课程页发给 Claude。

### 怎么做（按顺序）
1. **先看那一周的笔记再做**：网站“课程 → BUSI 1772 → 第 n 周”的预习包和课堂笔记（10–15 分钟）。不要先做后看。
2. **自己做**，不查答案、不用 AI——目的是发现自己哪里不懂。
3. 交卷后到**结果页（Review）**：一般能看到每道题、你的答案、正确答案（有时还有解释）。
4. **截图结果页**：每道题都要截到——题目、所有选项、你选的、正确答案。一页截不完就分几张。
5. 如果 Moodle 允许重做，**先别重做**，等 Claude 讲完错题再做一次。

### 发给 Claude 的格式
- 每周一条消息，开头写：**“1772 第 1 周自测”**，然后附截图。
- 加一句：**几题做对 / 总共几题，哪几题是猜的**（猜对的也算不懂）。
- Claude 会：逐题讲解（中文 + 关键英文术语）→ 整理进下面的**错题本** → 标出期末最可能考的知识点。
