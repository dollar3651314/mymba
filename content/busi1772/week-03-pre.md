## 这节课一句话
**后果主义**看结果好坏；市场能提高大家的福利，但只在规则被遵守时才成立。**Heath 的市场失灵方法（MFA）**：经理应该追求利润，但**不能利用市场失灵**赚钱——大众汽车排放造假错就错在利用了信息不对称和污染外部性。

## 要点（中文讲解，按课件顺序）

**0. 大众“柴油门”**：2015 年 9 月美国环保署发现大众在柴油发动机里装程序，**只在实验室测试时启动排放控制**，2008–2015 年造成超标污染。一年后股价仍跌 30%；2017 年 4 月被判 28 亿美元刑事罚款。
- 问题：**从后果主义角度，大众对顾客撒谎为什么是错的？**

**1. 后果主义和功利主义**
- 后果主义：行为应带来好结果、避免坏结果，对错看**净效果**（好处 − 坏处）。所以**没有行为本身就是好或坏，也没有绝对的权利**——撒谎甚至杀人，如果净效果最大，理论上也能被辩护。
- 福利（utility）：古典功利主义是**享乐主义**（快乐 − 痛苦）；现代功利主义是**偏好满足**（包括不一定“快乐”的偏好，比如读大学）。
- 功利主义的原则：“**使总效用最大化**”（Mill 1863；Rachels & Rachels 2012），三个特点：
  - 公平：每个人的效用权重相同（不偏不倚）
  - 加总：所有受影响的人都算进去（普遍主义）
  - 最大化：只有一个正确选项（要求很高）
- 课件把伦理理论分四类：后果主义（净效果最大）、义务论（平衡冲突的权利）、自由主义（在价值观不同的人之间找妥协）、美德伦理（通过习惯养成美德）。

**2. 市场怎样提高福利：支持私有财产和市场的论证**
- **保护政治自由**（义务论，Friedman）：经济自由是政治自由的手段；是对共产主义的回应。
- **提高效率**（后果主义）：
  - Hayek 的**价格机制**：中央计划处理不了现代经济的海量信息，分散决策靠价格协调更有效。
  - Schumpeter 的**创造性破坏**：新商业模式取代旧的，竞争逼企业不断创新。
  - Keynes 的**国家干预**：市场有繁荣–萧条周期，要靠公共投资、监管、再分配和福利来缓解。

**3. Heath 的市场失灵方法（MFA）**
- 伦理 → **职业伦理**（只适用于某个职业）→ **对抗性伦理**（竞争中的伦理）→ 市场失灵方法。
- 医生的类比：医生不能为了赚钱给不需要的病人做手术，那企业凭什么可以把自己的利益放在别人的权利之上？除非有很好的理由。
- **规则后果主义的逐利论证**（Heath 2014）：
  1. 经济的目标是满足人的需求
  2. 市场经济的功能是最有效地利用生产资源
  3. 在**受约束的**市场竞争中要求经理利润最大化，能使效率最大化
  - 结论：经理在道德上**必须**追求利润最大化（如果人人遵守这条规则，社会总效用最大）
- 原话：“经济整体的最终目标是满足人的需求……价格体系的功能是把资源引向最重要的需求。”（Heath 2014, p.15）
- 亚当·斯密的“**看不见的手**”：“我们的晚餐不是来自屠夫、酿酒师、面包师的仁慈，而是来自他们对自身利益的关注。”（1776）
- **帕累托改进**：至少让一个人变好、不让任何人变差。**帕累托最优**：再也没有帕累托改进的可能（均衡）。
- **完美市场的四个条件**：完全竞争、完全信息、没有外部性、没有搭便车。
- **现实中的四种市场失灵** → 监管办法：

| 市场失灵 | 例子 | 监管办法 |
|---|---|---|
| 不完全竞争 | 垄断、寡头、进入壁垒 | 反垄断法、禁止价格操纵 |
| 信息不对称 | 欺骗、虚假广告 | 广告规则、禁止内幕交易 |
| 负外部性 | 污染、金融风险 | 监管或征税、罚款 |
| 公共物品和搭便车 | 不付钱却享受 | 政府提供 |

- 监管有时会失败，所以私人企业必须遵守伦理义务。
- **MFA 的伦理论证**：
  1. 经济的目标是满足人的需求
  2. 逐利只有在带来经济效率、满足需求时才正当
  3. 利用市场失灵来逐利会造成低效率
  - 结论：**经理只有在不利用市场失灵的前提下才可以追求利润最大化**
- 和其他两个理论的区别：
  - 和 **Friedman** 不同：即使股东不想，利润最大化也是**义务**
  - 和 **Freeman** 不同：对利益相关者**没有直接义务**，只是某些策略不能用

| 好的逐利策略 | 有害的逐利策略 |
|---|---|
| 设计新产品、创新 | 消灭竞争、设进入壁垒、操纵价格 |
| 只靠降价或提高质量竞争 | 内幕交易、欺骗性广告 |
| 诚实有效的营销（≠ 大众） | 把成本外部化（污染、金融风险） |
| | 搭社会服务和基础设施的便车 |
| | 反对纠正市场失灵的监管 |

- 例子：**匈牙利“炖肉资本主义”**——经济自由化后，有人在辣椒粉里掺含铅的红色油漆，因为竞争变成了比谁的辣椒粉“好看”而不是“好”。
- **大众案**：虚假广告错，不只因为撒谎本身错，还因为它利用了两种市场失灵：**信息不对称**（厂商和消费者之间）和**负外部性**（污染），降低了市场效率。

**4. 对 MFA 的反对意见**
- **a. 我们看重的不只是效率**：经理的责任可能超出“不利用市场失灵”，比如义务论要求尊重所有利益相关者的权利，哪怕牺牲一些效率。Heath（像 Friedman 一样）回应：监管是政府的事；**制度分工**——先由市场把蛋糕做大，再由政府分配。
- **b. 次优理论**（Lipsey & Lancaster 1956）：反驳“越接近完美市场就越接近完美效率”这个假设——个人层面不利用市场失灵，不能保证整体效率提高。Heath 回应：在更理想的市场条件下，每一次自愿交易仍然是帕累托改进；“这不是说效率标准没有规范力，只是说我们不能做大而笼统的概括……商业中的道德推理必须更看具体情境。”（Heath 2014, p.40）

**5. Tutorial 里的重点**
- **论文常见错误**（课件原话）：**完全竞争市场 ≠ “自由”或“不受监管”的市场**。国家必须大量干预，市场才能存在、才能接近帕累托条件。没有监管，市场就不运转。
- **讨论：反对“非生产性广告”**——Heath (2014, p.12)：Molson 和 Labatt 每年花 2 亿美元做广告，研究显示这种竞争是**零和**的；如果广告的骚扰价值超过娱乐价值，社会会因为两家停止广告而更好。
  - 反对所有广告：给大企业不当优势、给新来者设进入壁垒（但有时帮初创企业建立品牌）。
  - 反对部分广告：虚假或欺骗性广告利用信息不对称；广告军备竞赛浪费资源、抬高价格；广告昂贵又随机（但技术让它变便宜）。
  - 广告的好处：增加市场信息流通；可以是品牌价值的一部分。
- 讨论：你同意“逐利的后果主义论证”（“贪婪是好的”）吗？经理唯一的责任就是不利用市场失灵吗？

## 可以在课上说的英文
- "From a consequentialist view, Volkswagen was wrong because it exploited information asymmetry and created negative externalities." —— 从后果主义的角度看，大众汽车做错了，因为它利用了信息不对称，并造成了负外部性。
- "Perfectly competitive markets are not the same as unregulated markets." —— 完全竞争市场不等于不受监管的市场。
- "Heath argues that managers must maximise profits, but only without exploiting market failures." —— Heath 认为管理者必须追求利润最大化，但前提是不能利用市场失灵。
- "Advertising can be zero-sum, but it also gives consumers useful information." —— 广告可能是零和的，但它也给消费者提供了有用的信息。
- "Unlike Friedman, Heath says profit maximisation is an obligation even if shareholders don't want it." —— 和 Friedman 不同，Heath 说利润最大化是一种义务，即使股东并不想要。
