## 本节重点（中文讲解）

1. **课程定位**：重点不是算法和写代码，而是理解数据、用数据做决策。管理者要提出正确的问题、挑战已有的假设、解读数据。
2. **决策的本质**：在多个选项中选一个行动方案，不是对错（0 或 1），而是比较哪个更好；每个选项都有权衡（trade-offs），目标是做出**站得住脚的选择**（defensible choice）。
3. **决策类型**
   - 程序化决策：重复、常规，有规则（例如经理只能批准 100 万美元以下的采购）。
   - 非程序化决策：新颖、没有模板（进入新市场、开发新产品），**数据分析在这里最有价值**。
   - 运营决策（短期、优化现有绩效）vs. 战略决策（高层、长期）。
4. **结构化决策五步**：识别问题 → 收集数据 → 分析和比较选项 → 执行 → 反馈评估。最常见的错误是**跳过问题定义**，直接冲向解决方案。数据要重“相关性”而不是“数量”；跨国数据要先标准化。
5. **数据三角验证**（triangulation）：重要决策不要只靠一个数据源，要用财务、运营、市场等多个来源交叉验证。关键不在复杂，而在纪律。
6. **数据类型**：结构化（表格，告诉你“发生了什么”）vs. 非结构化（评论、社交媒体，能提供早期信号和“为什么”）；定量（多少）vs. 定性（为什么、怎么样）；实时数据。
7. **四种分析**：描述性（发生了什么）→ 诊断性（为什么发生）→ 预测性（会发生什么）→ 规范性（应该怎么做）。
   - ⚠️ 录音总结说“描述性分析价值最高，越往后价值越低”，这和常见的分析成熟度模型（越往后难度和价值都越高）相反，**可能是转写误解，请对照课件确认**。
8. **认知偏差**：确认偏误（只看支持自己观点的信息）、锚定效应（过度依赖第一个信息，例如谈判时的首次报价）、过度自信（凭过去的成功低估新风险）。应对：设计决策流程，鼓励反对意见。
9. **反馈循环**：决策前写下假设，决策后对比结果，把决策变成持续学习。亚马逊把大多数决策视为可逆的，上线后持续监控点击率、转化率并迭代。
10. **案例**：Netflix 放弃 DVD 转向流媒体（数据不完美时的“有计算的风险”）；Zara 用实时销售数据调整生产和库存；亚马逊推荐系统整合购买历史、浏览和评价（三角验证）。
11. **金句**：“并非所有重要的东西都能被计算，也并非所有能被计算的东西都重要。”数据是“探照灯”，不是人类判断的替代品。

## 小组练习：国际扩张决策
你是 CEO，公司卖可持续环保产品，本地市场表现好，考虑国际扩张。
- 先用 **PESTLE**（政治、经济、社会、技术、环境、法律）评估目标国家。
- 需要的数据：市场数据、消费者分析、成本预测、标准和法规。
- 还要考虑：前期投资、市场吸引力、运营可行性、财务可行性（ROI、回收期、利润率）、文化适配、竞争对手、税务和关税、汇率和供应链风险。
- **老师强调**：评分不只看答案，更看你的**推理过程、用了哪些数据、做了什么假设、怎么论证立场**。这个思路直接适用于 American Egg 小组展示。

## 关键概念与术语

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| Defensible choice | 站得住脚的选择 | 能用证据和推理说明的决策 |
| Programmed / non-programmed decision | 程序化 / 非程序化决策 | 有规则可循 / 没有模板的新问题 |
| Operational / strategic decision | 运营 / 战略决策 | 短期优化 / 长期方向 |
| Data triangulation | 数据三角验证 | 多个来源交叉验证 |
| Structured / unstructured data | 结构化 / 非结构化数据 | 表格数据 / 文本图片等 |
| Descriptive / diagnostic / predictive / prescriptive analytics | 描述性 / 诊断性 / 预测性 / 规范性分析 | 发生了什么 / 为什么 / 会怎样 / 该怎么做 |
| Anchoring bias | 锚定效应 | 被第一个信息牵着走 |
| Overconfidence bias | 过度自信 | 高估自己的判断 |
| PESTLE | 宏观环境分析 | 政治、经济、社会、技术、环境、法律 |
| Feedback loop | 反馈循环 | 对比预期与结果，持续改进 |

**1. 决策的定义（可以写进报告）**：“通过识别决策、收集信息、评估备选方案来做出选择的过程。”数据驱动的决策推动创新、降低风险。

**2. 课件里的数据类型和数字（报告、展示都能用）**

| 类型 | 例子 | 课件里的数字 |
|---|---|---|
| 结构化 | 银行流水、销售记录 | 企业 90% 以上的电子表格是结构化数据 |
| 非结构化 | 社交媒体、图片、视频 | 80% 的企业数据是非结构化的；每天 5 亿条推文 |
| 半结构化 | 邮件（标题、时间结构化，正文不是）、JSON、XML | |
| 定性 | 亚马逊评论、访谈记录 | |
| 定量 | 电费单、销售额、网站流量 | |
| 大数据 | 物联网、大规模社交媒体 | 每天 45 亿次谷歌搜索；全球 90% 的数据产生于过去两年 |
| 实时数据 | 股价、Uber 的 GPS 匹配 | |

**3. 决策中的挑战**：数据过载、认知偏差、伦理困境（例：大众排放门，为利润牺牲伦理）。

**4. 案例**：Netflix 转型流媒体（问题：DVD 租赁下降 → 数据：消费者行为、市场趋势 → 决策：投资流媒体和原创内容）；Zara 用实时库存数据；**亚马逊推荐引擎贡献了 35% 的收入**；亚马逊上线新功能后收集反馈持续改进。

**5. 反馈循环四步**：收集数据 → 分析结果 → 调整改进 → 跟进。

**6. 课件总结的四个工具**：三角验证、识别认知偏差、反馈循环、预测分析。决策类型：战略、战术、程序化。

**7. Tutorial 练习：雕塑家的选择（第 1 次课做过的）**

| | 画廊方案 | 自己卖 |
|---|---|---|
| 件数 × 单价 | 10 × $10,000 | 6 × $12,000 |
| 收入 | $100,000 | $72,000 |
| 成本 | 佣金 50% $50,000、国际运输保险 $10,000、材料 $20,000、旅费 $5,000、工作室 $10,000，合计 **$95,000** | 本地运输保险 $4,800、材料 $15,000、营销拍摄 $3,000、旅费 $2,000、工作室 $10,000，合计 **$34,800** |
| **净剩现金** | **$5,000** | **$37,200** |

结论：只看收入画廊方案更好，算完成本后自己卖多剩 $32,200。课件的四句总结：第一眼看起来好的决策，数字算清楚后可能改变；**只看收入不能判断方案好坏**；简单的表和图能很快看出取舍；**数据支持判断，但不取代判断**。仍然要担心的假设：6 个月真能每月卖出一件吗？$12,000 的价格有人买吗？

**8. Tutorial 课件提醒的作业规划**：报告需要的内容在**第 2、3 周讲座**里讲；尽早组队，定好多久碰一次面，每周学的东西怎么用到作业上。
