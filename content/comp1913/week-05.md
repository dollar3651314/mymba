## 本节重点（中文讲解，按课堂顺序）

**1. 这门课的目标（1:49–4:43）**
不是把你培养成数据科学家，而是让你成为**看得懂统计和仪表盘、会问对问题**的决策者。例子：招聘广告常写“**中位数**薪资”而不是平均数——少数人工资很高会把平均数拉高，中位数更能代表一般水平（2:22–3:15）。

**2. 一图胜千言（7:45–17:00）**
- 给领导看的不是 Excel 表，而是简单的图和仪表盘；好的图能马上看出**趋势、对比和关系**。
- **折线图**适合看随时间的变化（时间序列）（9:21）。
- 原始数据表 vs. 同样数据画成图：表格要花很多力气才能看懂，图一眼就能看出谁高谁低；再**排序**会更清楚（10:47–14:24）。
- 三个变量放在一张图里（两个 Y 轴，例如人均 GDP 和预期寿命）能看出关系、提出假设——但**变量太多会让图难懂**：“信息越多不一定越好”（14:37–17:00）。

**3. 描述统计：集中趋势（18:05–26:05）**
- **平均数（mean）**：数据比较稳定、没有极端值时最好用。
- **中位数（median）**：数据有极端值、分布偏斜时更有意义（薪资、房价）；算的时候要先把数字**从小到大排序**。
- **众数（mode）**：出现次数最多的值，例如卖得最多的产品，适合看顾客行为。
- 课件里附了对应的 Excel 函数（AVERAGE、MEDIAN、MODE 等），tutorial 里会用到。

**4. 描述统计：离散程度（26:05–42:58）**
- **全距（range）**= 最大值 − 最小值，最快看出波动大小。例：房价从 10 万到 8000 万美元，全距很大 → 可能有负担能力或市场分层问题；班上最低 95 分 vs. 最低 20 分，平均数一样也代表完全不同的情况（32:01–35:59）。
- **月收入**：每月都在 2 万–2.5 万之间，比忽高忽低更稳定，更好预测（35:11）。
- **方差（variance）**：数据偏离平均数的程度；方差大 = 不稳定、风险高、难预测。例：电商的“双 11”、圣诞季造成的**季节性**波动（36:59–39:50）。
- **标准差（standard deviation）**：把方差换回**和原数据相同的单位**，更好解释。可以当作“正常波动范围”，超出这个范围就要注意（39:50–42:58）。
- 管理者结论：平均数高不一定好，波动太大可能代表不平等或风险；平均数一般但很稳定，可能更可取。

**5. 选对图（42:58–50:07）**
| 图 | 适合 |
|---|---|
| 柱状图 bar chart | 比较不同类别（各地区销售、各部门表现）；排序后更清楚 |
| 饼图 pie chart | 部分占整体（加起来 100%） |
| 直方图 histogram | 看数据怎样分布（价格、年龄） |
| 散点图 scatter plot | 看两个数值变量的关系（营销费用 vs. 收入），正相关 / 负相关 |
| 箱线图 box plot | 看分布和**离群值** |
| 折线图 line chart | 随时间的趋势 |
- **坏例子**：柱子重叠、颜色太多的“拥挤图”——看的人要先费力解读，容易误解，开会时没人想看。**每张图只回答一个问题、突出一个结论**（47:13–50:07）。

**6. 案例：幸福指数（50:07–54:54）**
问题：**人均 GDP 越高，人们越幸福吗？** 用散点图，每个点是一个国家，加一条趋势线 → **正相关**。重点不是记函数，而是学会**把商业问题框定好、选合适的图**。

**7. 案例：销售数据（54:54–57:45）**
按地区比较销售：用**柱状图**最容易比较；用饼图也不算错，但各地区数值接近时，饼图里几块差不多大，很难比较。**最好的图取决于你要回答的问题。**

**8. 看图的人是谁（57:45–1:00:51）**
- **高层**：简单、突出关键结果和趋势，不要计算细节；一句清楚的标题结论。
- **中层经理**：多一点细节，例如按地区、产品拆分。
- **技术团队**：可以看分布、关系等更多细节。
- 做图前先问：**我的听众是谁？他们要做什么决定？**

**9. 好图的规矩（1:00:51–1:05:11）**
保持简单（一张图一个主要意思）；选对图；**坐标轴和单位要标清楚**；不要用夸张的字体、颜色；比较 10–20 个类别时**不要每根柱子一个颜色**，用一种颜色更清楚。
结语：数据给决策提供结构，但**不能代替判断**。

**10. Tableau 演示（2:04:34–2:10:38）**
把地区拖到 X 轴、收入拖到 Y 轴就出柱状图；也能一键换成饼图。用散点图看“营销费用增加，收入会不会增加”——这份数据里**看不出明显关系**。

## 关键概念与术语
| 英文 | 中文 | 一句话解释 |
|---|---|---|
| Descriptive statistics | 描述统计 | 用几个数概括一堆数据 |
| Central tendency | 集中趋势 | “典型值”在哪里 |
| Mean / median / mode | 平均数 / 中位数 / 众数 | 三种典型值 |
| Dispersion | 离散程度 | 数据有多分散 |
| Range | 全距 | 最大值 − 最小值 |
| Variance | 方差 | 偏离平均数的程度 |
| Standard deviation | 标准差 | 和原数据同单位的波动 |
| Outlier | 离群值 | 特别高或特别低的值 |
| Seasonality | 季节性 | 每年固定时期的波动 |
| Bar / pie / line chart | 柱状图 / 饼图 / 折线图 | 比较 / 占比 / 趋势 |
| Histogram / box plot / scatter plot | 直方图 / 箱线图 / 散点图 | 分布 / 离群值 / 关系 |
| Trend line | 趋势线 | 散点图里表示总体方向的线 |
| Cognitive overload | 认知负担过重 | 图太复杂，看的人吃不消 |
