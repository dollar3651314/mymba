## 这节课一句话
用**描述统计**（平均数、中位数、众数、全距、方差、标准差）把一堆数字概括成几个数，再用**合适的图**（柱状图、直方图、散点图、箱线图……）把规律讲清楚；图要简单、诚实、有标签，不能误导读者。

## 要点（中文讲解，按课件顺序）

**1. 为什么要可视化（第 3–7 页）**
- “一图胜千言”：把复杂数据变简单；突出规律、趋势和关系；帮助做更好的决策。
- 课件第 4–7 页是同一份数据“表格 vs. 图”的对比（图片，没有文字）。

**2. 什么是描述统计（第 8–9 页）**
- 定义：**概括和描述**数据集主要特征的统计。分两类：
  - **集中趋势**（数据的“中心”在哪）：平均数、中位数、众数
  - **离散程度**（数据有多“散”）：全距、方差、标准差
- 什么时候用哪个：

| 指标 | 适合 | 课件例子 |
|---|---|---|
| 平均数 Mean | 连续数据、**没有极端值** | 一个地区的平均收入 |
| 中位数 Median | **偏态数据或有极端值** | 房价中位数 |
| 众数 Mode | 类别数据或离散数据 | 卖得最多的产品 |
| 全距 Range | 快速看数据跨度 | 产品价格区间 |
| 方差 Variance | 数据离平均数有多远；方差大 = 很分散 | — |
| 标准差 SD | 方差开根号，**单位和原数据一样**，更好解释 | 月销售额的波动 |

**3. 集中趋势的例子（第 10–11 页）**
- 数据 [5, 8, 10, 10, 12]：平均数 9、中位数 10、众数 10。
- Excel：平均数 `=AVERAGE(A1:A5)`；中位数 `=MEDIAN(A1:A5)`；众数 `=MODE.SNGL(A1:A5)`。
- **工资例子（重点）**：£30k、£35k、£40k、£50k、£120k → 平均数 £55k，但被 £120k 这个**极端值**拉高了；中位数 £40k 更能代表“典型”工资。
- 众数例子：顾客喜欢的颜色 红、蓝、红、绿、红、蓝 → 众数是红色（类别数据只能用众数）。

**4. 离散程度的例子（第 12–15 页）**
- 全距 = 最大值 − 最小值（例：12 − 5 = 7；房价 £600k − £200k = £400k）。
- 方差 = 每个数和平均数之差的平方，再求平均。Excel：`=VAR.P(A1:A5)`。
- 标准差 = 方差开根号。Excel：`=STDEV.P(A1:A5)`。例：考试分数 60、70、80、90、100 → 方差 200，标准差 ≈ 14.14，即“大多数分数离平均分大约 14 分”。
- ⚠️ **课件第 14–15 页的月销售额例子算错了**：五个数 £10k、12k、14k、18k、20k，平方差加起来是 68,800,000，除以 5 应该是 **13,760,000**（课件写 13,360,000），标准差应约 **3,709**（课件写 3,654）。Claude 用两种方法核对过。自己用 Excel 算一遍就能看出来——这正好是练习“核对数字”的好机会。
- 小知识（Claude 补充，课件没讲）：`VAR.P` / `STDEV.P` 是把数据当成**全体（population）**；如果数据只是**样本（sample）**，一般用 `VAR.S` / `STDEV.S`，结果会稍大一点。tutorial 按课件用 `.P` 就行，写报告或做展示时说明你用了哪一个。

**5. 常见图表和 Excel 操作（第 16 页）**

| 图 | 用来 | 课件例子 | Excel |
|---|---|---|---|
| 柱状图 / 条形图 Bar chart | 比较**类别** | 各地区销售额 | 选数据 → 插入 → 图表 → 柱状图 |
| 直方图 Histogram | 看**分布** | 产品价格落在各区间的数量 | 数据分析工具库（Data Analysis ToolPak）→ 直方图 |
| 散点图 Scatter plot | 看两个数字变量的**关系** | 收入 vs. 营销支出 | 选数据 → 插入 → 散点图 |
| 箱线图 Box plot | 看**极端值和分散程度** | 找出工资异常值 | Excel 2016 以上：插入 → 箱形图 |

- 第 17–18 页是“坏图”示例（图片）：**柱子重叠、不必要的复杂**，让人看不懂。

**6. 两个课堂案例（第 19–20 页）**
- **案例 1：幸福指数**——GDP 人均 vs. 幸福分数做散点图，加趋势线（右键点 → 添加趋势线），看 GDP 越高是不是越幸福。
- **案例 2：零售销售**——按地区做柱状图，找表现最好的地区。

**7. 讨论题（第 22–23 页）**
- “比较四个地区的销售，用什么图？”→ 课件答案：**柱状图**，因为地区是类别数据。
- “给不同的听众，你会怎样改图？”（例如给高管看要一眼看出结论，给分析师看可以多放细节。）

**8. 可视化的好做法（第 25 页）**
- 简单清楚；用合适的图表类型；**坐标轴要有标签和单位**；不要杂乱、**不要用误导性的刻度**。
- 好图：清楚的标题、好读的字体、有意义的颜色。坏图：**滥用 3D 效果**、标签挤成一团。

**9. 总结（第 26–28 页）**：描述统计高效地概括数据；可视化让数据更好懂；要多练。课后任务：把一份数据可视化并解读结果。“决策既是艺术也是科学，把数据和批判性思维结合起来。”

## Tutorial 5：Excel 练习（按步骤说明，中文讲解）

> 两份练习最后都问同样三个问题：**① 关键规律是什么？② 这能支持什么决策？③ 做决策前要小心什么局限 / 还缺什么信息？** ——这就是报告和展示里“描述 → 分析 → 评价”的写法。

### 练习 A：幸福指数（Happiness Index）
**数据**：文件有 4 个工作表——`Happiness-Data`（20 个国家）、`Countries without names`（同样的数据，国家名换成 Country A–T）、`Central Tendency`（平均数、中位数、众数）、`Countries- 30`（30 个国家，多一列 Source）。列：国家、幸福分数、人均 GDP（美元）、预期寿命（年）、自由度分数（0–1）。

| 步骤 | 做什么 | 要回答的问题 |
|---|---|---|
| 2 | 选“国家”和“幸福分数”两列 → 插入 → 柱状图；标题 “Happiness Score by Country”；可加数据标签、旋转横轴文字 | 哪些国家更幸福 / 不幸福？可能是什么原因？ |
| 3 | 选“人均 GDP”和“幸福分数” → 插入 → 散点图；右键点 → 添加趋势线；标题 “Relationship Between GDP and Happiness” | GDP 越高越幸福吗？有没有例外？ |
| 4（选做） | 组合图：插入 → 组合图；GDP 放主坐标轴，自由度分数放次坐标轴 | 哪些变量适合放在一起比较？哪些因为**刻度差太多**放在一起很难看？ |
| 5 | 选“国家”和“预期寿命” → 插入 → 折线图（带数据标记）；标题 “Life Expectancy Across Countries” | 有什么规律？对决策者理解“幸福感”有什么帮助？ |

- 说明里的提示：**刻度差很多的变量（GDP 几万 vs. 自由度 0–1）分开画**；一定要放一起，就先换算成百分比等可比的单位。
- ⚠️ 小思考（Claude 补充）：第 5 步用**折线图**画“各个国家”的预期寿命——国家是类别、不是时间顺序，按课件第 16 页和必读论文的规则，**柱状图更合适**。课上可以拿来讨论。

**自己做完再核对**（Claude 用同一份数据算的，20 个国家）：
- 幸福分数：平均 7.10、中位数 7.15、最低 5.7、最高 8.3；样本标准差 ≈ 0.84。
- 人均 GDP：平均 29,900、中位数 30,500。
- 幸福分数和人均 GDP 的相关系数 `=CORREL(...)` ≈ **0.98**（几乎是一条直线）。
- ⚠️ **`Central Tendency` 表里的“众数”一行是错的**：幸福分数、GDP、自由度这三列**没有任何重复的数**，所以没有众数（Excel `MODE.SNGL` 会显示 `#N/A`）；表里写的 5.7、13,000、0.55 其实是**最小值**（都是“美国”那一行）。预期寿命有三个数各出现两次（76、78、80），`MODE.SNGL` 会返回 80，表里却写 76。
- ⚠️ **这份数据是练习用的**：`Countries- 30` 表把来源标成 “World Happiness Report”，但数字和公开数据差得很远（例如美国人均 GDP 只有 13,000 美元，还是幸福分数最低的国家）。这本身就是一个好例子：**标了来源不等于数据可信**——评估 Bain 报告时也要这样检查。

### 练习 B：销售数据（Sales Data）
**数据**：工作表 `Main Data-Sheet`，20 种产品；列：产品、销量（件）、收入（美元）、地区（东南西北）、营销支出（美元）。另外还有 `Sum of Revnues by Region`、`Pivot Table`、`Notes` 三个表。

| 步骤 | 做什么 | 要回答的问题 |
|---|---|---|
| A 柱状图 | “地区”+“销量” → 簇状条形图；标题 “Sales by Region”；加数据标签 | 哪个地区卖得好？经理做决定前还需要什么信息？ |
| B 散点图 | “销量”+“收入” → 散点图；加趋势线，勾选“显示公式” | 销量越高收入越高吗？有没有例外？ |
| C 饼图 | “产品”+“营销支出” → 饼图；数据标签显示百分比 | 营销费用在产品之间分得均匀吗？和销量 / 收入匹配吗？ |
| D 折线图 | “产品”+“销量” → 折线图（带标记） | 哪些产品卖得多 / 少？对以后的计划有什么启示？ |
| E 组合图 | “地区”+“销量”+“收入” → 组合图：销量用簇状柱形，收入用折线放**次坐标轴**；两个坐标轴都加标题 | 销量高的地区收入也高吗？为什么销量和收入会不一致？ |
| F 集中趋势 | 对销量和收入算 `=AVERAGE(范围)`、`=MEDIAN(范围)`、`=MODE.SNGL(范围)`，做成表放在图下面，再用柱状图比较三个数 | 平均数、中位数、众数说明了什么？**平均数会不会误导？** |

- ⚠️ **实操提示**（Claude 补充）：步骤 A 和 E 如果直接选 20 行数据，会画出 20 根柱子、地区名重复。要先**按地区汇总**：插入 → 数据透视表，或用 `=SUMIF(地区列,"North",销量列)`。
- ⚠️ **文件里现成的 `Pivot Table` 和 `Sum of Revnues by Region` 两个表和主数据对不上**（例如东区销量写 1,630，主数据加起来只有 640）。不要直接用，**自己重新汇总**。
- ⚠️ 饼图有 20 块——必读论文规定“**一张图不超过 6 个类别**”，饼图里数值很小或很接近时应改用柱状图。可以讨论这一步是不是好选择。

**自己做完再核对**（Claude 用主数据算的）：

| 地区 | 销量 | 收入 |
|---|---|---|
| North | 840 | 182,000 |
| South | 735 | 217,500 |
| East | 640 | **297,000** |
| West | 745 | 188,500 |

- **北区卖得最多，东区赚得最多**——因为东区卖的是贵东西（投影仪 1,000 美元一台、智能手表 500 美元），这正是步骤 E 想让你发现的。
- 销量和收入的相关系数 ≈ **0.03**（几乎没关系）：产品单价从 50 美元（鼠标、充电器）到 1,000 美元（投影仪）不等，所以“卖得多 ≠ 赚得多”。
- 收入：平均 44,250、中位数 35,250——平均数被智能手机（120,000）拉高，**中位数更能代表典型产品**。销量众数 150（笔记本电脑和台灯）；收入没有众数。
- 营销支出几乎都正好是“销量 × 100 美元”，只有**充电器**是 3,400（= 销量 × 10）——可能是录入错误，也可能是故意放的异常值，课上可以问。

## 必会术语（中英）

| 英文 | 中文 | 一句话 |
|---|---|---|
| Descriptive statistics | 描述统计 | 概括数据的主要特征 |
| Central tendency | 集中趋势 | 数据的“中心” |
| Mean / Median / Mode | 平均数 / 中位数 / 众数 | 三种“中心” |
| Outlier | 极端值 / 异常值 | 特别大或特别小的数，会拉偏平均数 |
| Skewed data | 偏态数据 | 一边拖着长尾巴 |
| Dispersion / spread | 离散程度 | 数据有多分散 |
| Range | 全距 | 最大 − 最小 |
| Variance | 方差 | 离平均数距离的平方的平均 |
| Standard deviation (SD) | 标准差 | 方差开根号，单位和原数据一样 |
| Population vs. sample | 总体 vs. 样本 | STDEV.P vs. STDEV.S |
| Bar chart / Histogram | 柱状图 / 直方图 | 比类别 / 看分布 |
| Scatter plot / Trendline | 散点图 / 趋势线 | 看两个变量的关系 |
| Box plot | 箱线图 | 看分散和异常值 |
| Pie chart / Donut chart | 饼图 / 环形图 | 部分占整体，加起来要 100% |
| Combo chart / Secondary axis | 组合图 / 次坐标轴 | 两种单位放一张图 |
| Data label / Axis title / Legend | 数据标签 / 坐标轴标题 / 图例 | 好图的基本要素 |
| Misleading scale | 误导性刻度 | 例如 Y 轴不从 0 开始 |
| Cognitive load | 认知负荷 | 图越乱，读者越累 |

**22 条通用好做法（中文意译，按论文表 III 顺序，可当检查表）**：
1. 标签清楚、简单、简短 2. 字体简洁 3. 必要时才加额外标签 4. 用读者熟悉的词 5. 不要全用大写 6. 类别要排序（按数值、字母或逻辑） 7. 不同类别用不同颜色 8. 颜色和类别的含义对应（如现实中的颜色） 9. 照顾色盲读者：**不要红绿同用**，可换成蓝和橙 10. **一张图不超过 6 个类别** 11. 颜色越少越好 12. 降低认知负荷：去掉多余的边框、背景、参考线 13. **数据诚实、真实、可信，不歪曲** 14. 留白 15. 用格式塔“相似性”原则 16. 用大小、颜色、加粗等突出重点 17. **轴尽量从 0 开始，不从 0 开始要注明原因** 18. 刻度按自然间隔 19. **不超过两个坐标轴** 20. 不要截断坐标轴 21. **不要用 3D 和倾斜效果** 22. 结构清晰、简单易懂

**按图表类型的规则（论文表 IV，摘要）**：
- 柱状图（平均数、中位数、众数、频数）：有坐标轴就不必在柱子上再标数；柱子之间留至少半根柱子宽的间隔。
- 散点图（回归、相关）：用一条直线（趋势线）看相关类型，线的颜色和点不同。
- 直方图（频数）：柱子之间只留很小的空隙；一般所有柱子同一颜色。
- 饼图（频数）：**加起来要 100%**；数值很小或很接近时**改用柱状图**；标签放在扇形里（放不下就放外面）；**不要把两张饼图并排比较**。
