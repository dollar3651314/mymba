## 要点（中文讲解）

**1. 讲座：McKinsey 2018 多元化与财务表现**
- 研究：1000 多家公司、12 个国家；问题是“多元化和财务表现相关吗？”
- 结论：性别多元化排名前 25% 的公司跑赢的可能性高 **21%**；族裔多元化前 25% 高 **33%**；差距在扩大。
- 为什么多元化可能有用：创新、理解多元市场、留住人才。
- **能相信 McKinsey 吗？**——这是相关还是因果？有没有其他因素？局限：没有控制所有外部因素；**自我报告偏差**；行业差异。
- 怎样检验因果：**回归分析**（控制其他变量）、**自然实验**（如新的多元化法律）、**对照组**（同行业相似公司比较）。
- 多元化 ≠ 包容；象征性雇用（tokenism）vs. 真正包容；心理安全感。
- 政策：欧盟董事会女性配额；美国自愿目标；亚洲领导层性别比例上升。
- （第 2 周 COMP 和 BUSI 1772 都提过这份报告“夸大结论、没排除反向因果”，这周深入讲。）

**2. Tutorial：评估报告图表的六个维度**
| 维度 | 要问的问题 |
|---|---|
| 清晰度和呈现 | 标题、标签、图例、颜色清楚吗？ |
| 证据质量和可信度 | 数据来源写了吗？可信吗？方法说明了吗？ |
| 准确性和图表类型 | 数字对吗？用的图表类型合适吗？ |
| 解读和信息 | 图想让你相信什么？结论站得住吗？ |
| 信息完整性 | 缺不缺定义、**样本量**、国家分类、实际数值、不确定性、方法？ |
| 目标读者 | 写给谁看的？ |

- **活动 1**（10 分钟浏览 BCG 报告）：① 目标读者是谁？凭什么证据？② 用了什么数据来源和方法？在哪里写的？③ 报告想说服读者相信或做什么？然后两人对比答案。
- **示范：BCG 图表 2**——想表明 2022/2023 到 2025 年，六个非洲国家对女性角色的社会态度变差了。问题：
  - 来源写的是“BCG Africa Women Voices Survey 2023/2025”，标题却写“2022–2025”——**年份不一致**，方法清楚吗？
  - 图讲的是一个强烈的“下降”故事——**每个国家、每个说法、每类受访者都一样强吗？**
  - 三个说法方向不同：有的“同意越多”代表态度变差，有的“同意越少”代表变差——读者容易看错。
- **小组活动**：评估分到的图——清楚、可信、对决策有用吗？读者会怎样理解？怎么改进？缺什么信息？偏差会误导读者吗？
- **写评估段落的公式**（课件目标）：**图表的问题 → 对解读的影响 → 对决策的影响 → 改进建议**。

**3. Excel 练习：多元化和财务表现（50 家公司的数据）**
- 数据列：公司名、收入（十亿美元）、利润率（%）、员工多元化指数、市值、ESG 分数。
- 第一阶段：算多元化指数和财务指标的**平均数**（`=AVERAGE`）、**中位数**（`=MEDIAN`）、**标准差**（`=STDEV.P`）；做柱状图（各公司多元化指数）、**散点图**（多元化指数 vs. 利润率）、可选热力图（条件格式色阶）。
- 第二阶段：提出假设（例：“多元化指数越高，财务表现越好”），用 **Pearson 相关系数** `=CORREL(...)`，或卡方检验 `=CHISQ.TEST(...)`（类别数据）。
- 第三阶段：2 分钟小展示，三个要点 + 截图 + 关键数字。
- **自己做完再核对**（Claude 用同一份数据算的）：多元化指数平均 0.765、中位数 0.78、标准差 0.139；利润率平均 14.96%；多元化指数和利润率的相关系数约 **−0.05**（几乎没有关系），和 ESG 分数约 0.06。→ 在这份数据里**找不到** McKinsey 说的那种关系。另外数据明显是练习用的虚构数据（例如苹果利润率只有 5.49%），这一点本身也是“检查数据质量”的好例子。

## 必会术语（中英）
| 英文 | 中文 | 一句话 |
|---|---|---|
| Intended audience | 目标读者 | 报告写给谁 |
| Methodology | 研究方法 | 数据怎么收集分析的 |
| Exhibit | 图表（咨询报告用语） | Exhibit 2 = 图表 2 |
| Source note | 来源注释 | 图下面写的数据出处 |
| Sample size | 样本量 | n = 多少 |
| Uncertainty / margin of error | 不确定性 / 误差范围 | 数字有多可靠 |
| Mean / median / standard deviation | 平均数 / 中位数 / 标准差 | 描述统计三件套 |
| Scatter plot | 散点图 | 看两个变量的关系 |
| Pearson correlation | 皮尔逊相关系数 | −1 到 1 |
| Regression | 回归 | 控制其他变量看影响 |
| Control group | 对照组 | 用来比较的组 |
| Self-reporting bias | 自我报告偏差 | 自己报的数据可能不准 |
| Tokenism | 象征性雇用 | 只为好看而招人 |

## 可以在课上说的英文
- "The intended audience seems to be investors and policymakers, because the report ends with funding recommendations." —— 目标读者似乎是投资者和政策制定者，因为报告最后给出了融资建议。
- "The source note says 2023/2025, but the title says 2022–2025, so the time frame is unclear." —— 来源注释写的是 2023/2025，但标题写的是 2022–2025，所以时间范围不清楚。
- "The chart doesn't show the sample size, so we can't judge how reliable it is." —— 图表没有显示样本量，所以我们无法判断它有多可靠。
- "In our data, the correlation between diversity and profit margin is close to zero." —— 在我们的数据里，多样性和利润率之间的相关性接近于零。
- "A clustered bar chart would make the comparison across countries clearer." —— 用簇状柱形图会让各国之间的比较更清楚。
