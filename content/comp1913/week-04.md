## 本节重点（中文讲解，按课堂顺序）

**1. 为什么要假设（1:35–5:48）**
工作中常常拿不到完整数据，只能做“假设”（assumption）。**假设（hypothesis）**是把“你认为可能成立的事”写成一句清楚的话，例如“服务重新设计后，顾客满意度提高了”。调查数据让我们用证据检验它，而不是靠直觉或“会议室里嗓门最大的人”。重点不是复杂的数学，而是**有纪律的思考**：比较“观察到的”和“如果什么都没变应该看到的”——差别是真实的，还是随机波动？好处：减少偏见、决策更有底气，能向高层解释。

**2. 假设检验四步（6:09–9:22）**
1. **提出假设**：先把商业问题说清楚（例：新数字渠道上线后满意度提高了吗？海外顾客和本地顾客对品牌的看法不同吗？）
2. **定判断标准**：**事先**约定多强的证据才算数——像项目开始**前**定 KPI，而不是看到结果再“挪球门”。
3. **计算检验统计量**：不用手算，但要懂数字在说什么。
4. **做决定**：检验结果不替你做决定，只给证据；管理者再决定推广、改进还是暂停深入调查。

**3. 第 1 步详解：零假设和备择假设（10:06–20:31）**
- **零假设 H₀**（录音里转成 “now hypothesis”）：没有差别 / 没有改善，例如“服务上线后满意度没变”。
- **备择假设 H₁**：管理层希望或怀疑成立的，例如“满意度提高了”。
- 不要把很多问题塞进一个问题陈述。
- **好假设要可检验、可测量**：不说“顾客更开心”（你的开心和我的不一样），要说“平均满意度分数提高了”；问卷用 1–5 分量表，多个问题合成一个分数（例：**NPS 净推荐值**）（16:59–17:32）。
- 数据要对：调查谁（样本要能代表总体）、问对问题；问卷设计差，再好的假设也没用。

**4. 什么是好假设（20:31–26:18）**
- 把经验和直觉变成**可以用数据检验**的句子：说清楚**哪两个变量**、预期什么关系。例：“引入弹性工作后，员工敬业度分数更高”。
- 通常有**自变量**（一个变化：新政策、新营销活动）和**因变量**（结果：满意度、生产率）。
- 例：“这个产品太贵了”是个人判断，不能检验；加上明确条件（具体价格点）就变成假设：“价格超过 X 的产品被顾客认为贵”。
- **关键结论**：先把直觉变成精确、可测量的句子，再去分析数据；否则浪费资源。

**5. 研究问题 vs. 假设（26:20–29:33）**
- 不是每个研究都从假设开始；在陌生、变化快的环境（新兴市场、贸易政策变化），先提**研究问题**。
- 三类研究问题：**描述性**（发生了什么，例：多少跨国企业进入某地区）、**探索性**（几乎未知，找规律，例：企业怎样应对新监管）、**预测性**（某条件下可能发生什么）。
- 理解加深后，研究问题再变成可检验的假设。

**6. 单向 / 双向假设（29:33–40:41）**
- 例：探索性问题“AI 投资对盈利有没有影响？” → **单向假设**“AI 投资越高，盈利越高”（有明确方向，适合有理论或经验依据时）。
- **正相关**：A 增 B 也增（投资增加 → 市场份额提高）；**负相关**：A 增 B 减（贸易壁垒提高 → 外国投资减少）。
- **双向（two-tailed）假设**：只说有关系，不说方向——适合复杂、不确定的情境。老师的例子：AI 投资对盈利的影响**因行业而不同**（科技行业直接提升产品和创新速度；非科技行业效果间接、较慢）——这里“行业类型”是**调节变量**（moderating variable）。
- 零假设从“中立”出发：“AI 不会提高盈利，请证明给我看”——防止我们只看到自己期望的规律。

**7. 两个例子（42:57–48:16）**
- **自动库存系统**：H₀ = 系统更新后误差仍在可接受范围；H₁ = 物流经理担心更新后误差变多。拒绝 H₀ → 有理由检查更新、培训员工、调整流程；不拒绝 → 不做不必要的干预。
- **咖啡机奶泡**：H₀ = 平均奶泡厚度仍是 1 cm；H₁ = 不再是 1 cm（**双向**：可能变厚也可能变薄）。
- ⚠️ **“不拒绝 H₀”不等于证明什么都没发生**，只是现有数据证据不够（48:25–49:41）。

**8. 第 2 步：定判断标准（49:41–59:39）**
- **显著性水平 α**：通常 **5%**，表示愿意承担多大“误判有变化”的风险。
- 高风险、难以挽回的决定用更严格的 **1%**；早期探索性分析可以放宽到 **10%**。老师说：重点不是记哪个百分比配哪种情况，而是理解“α 反映组织的**风险偏好**”（53:59–54:45）。
- 例：公司基准假设“至少 80% 顾客满意”，调查结果明显更低、而且偶然出现的概率很小 → 推翻 80% 的假设（55:52）。
- **置信区间**：给出真实效果的一个范围，比 p 值更容易向别人解释。规则：如果 H₀ 的值（例如“0 变化”）**落在区间外** → 拒绝 H₀。例：员工生产率提高 **3%–12%**，不包含 0 → 新工作方式有正面效果，还能看出效果大概多大（57:25–59:39）。

**9. 四种测量尺度（59:39–1:03:38）**
| 尺度 | 特点 | 例子 |
|---|---|---|
| 定类 Nominal | 只是分类标签，没有大小 | 国家、行业、是 / 否 |
| 定序 Ordinal | 有顺序，但间隔不一定相等 | 满意度 1–5 分 |
| 定距 Interval | 间隔相等，**没有真正的 0** | 温度、日历日期 |
| 定比 Ratio | 有真正的 0，可以说“两倍” | 大多数财务和运营数据（收入、销量） |
**测量尺度决定能用什么分析**——先弄清楚你手上是什么数据。

**10. 第 3 步：检验统计量（1:05:45–1:08:02）**
把样本数据汇总成一个数，可以看作**“距离”**：离“什么都没变”有多远。数值小 → 结果很普通，可能是偶然；数值大 → 不寻常，更可能是真实变化。不同数据用不同检验，但逻辑一样。

**11. 相关 vs. 回归（1:08:02–1:11:35）**
- **相关**：两个变量是否一起变（广告费高的市场销量是不是也高？）——**不说明因果**（上周的冰淇淋和鲨鱼）。
- **回归**：更进一步，估计“广告费增加多少，销量大概增加多少”——用于**预测和规划**。

**12. 常用检验方法（1:11:35–1:13:50；1:29:58–1:33:42）**
| 方法 | 什么时候用 |
|---|---|
| z 检验 / t 检验 | 比较平均数 |
| 独立样本 t 检验 | 比较两个不同的组（例：不同人群的薪资） |
| 配对 t 检验 | 同一组前后对比（例：政策变化前后的满意度） |
| 方差分析 ANOVA | 比较**三个以上**的组 |
| 卡方检验 Chi-square | **两个都是类别变量**（国家、品牌偏好、性别）是否有关联 |
| Spearman / Kendall | 定序数据（满意度等级） |
| Pearson 相关 | 两个都是数值变量（收入和广告费） |
“双变量分析”= 一次看两个变量的关系；更多变量叫“多变量”。

**13. 看懂 SPSS 输出（1:33:42–1:42:23）**
- **卡方**：只告诉你**有没有关联**，不说强弱和方向；重点看 **p 值**。老师的例子 p = 0.001（偶然出现的概率只有 0.1%），远低于 5% → 拒绝 H₀，两个变量有关联（但不说明原因）。
- **Pearson r**：−1 到 1，绝对值越接近 1 关系越强，正负号表示方向。例：身高和体重 **r = 0.714**，p ≈ 0 → 显著正相关；**r² = 0.51** → 体重的 51% 差异可以用身高解释，剩下 49% 来自饮食、运动、遗传等其他因素。

**14. 第 4 步：做决定（1:42:25–1:49:46）**
- **拒绝 H₀**：证据超过事先定的标准 → 有真实变化 / 关系 → 要采取行动（扩大、调整策略），但**不一定是因果**，具体怎么做还要再判断。
- **不拒绝 H₀**：证据不够 → 维持现状，不需要干预；不等于证明“没有效果”。
- 同学问“拒绝 / 不拒绝”太绕，老师也承认容易混。**记法：拒绝 H₀ = 有变化，要行动；不拒绝 H₀ = 没足够证据，照旧。**

## 关键概念与术语
| 英文 | 中文 | 一句话解释 |
|---|---|---|
| Hypothesis | 假设 | 可以用数据检验的一句话 |
| Null hypothesis (H₀) | 零假设 | 没有差别 / 没有关系（录音转成 “now hypothesis”） |
| Alternative hypothesis (H₁) | 备择假设 | 有差别 / 有关系 |
| One-tailed / two-tailed | 单向 / 双向 | 有没有预测方向 |
| Independent / dependent variable | 自变量 / 因变量 | 原因（变化）/ 结果 |
| Moderating variable | 调节变量 | 改变两个变量关系强弱的因素（例：行业） |
| Significance level (α) | 显著性水平 | 事先定的判断门槛，常用 5% |
| p-value | p 值 | H₀ 成立时得到这种结果的概率；< α 就拒绝 H₀ |
| Confidence interval | 置信区间 | 真实效果可能落在的范围 |
| Test statistic | 检验统计量 | 结果离“没变化”有多远 |
| Nominal / ordinal / interval / ratio | 定类 / 定序 / 定距 / 定比 | 四种测量尺度 |
| Correlation / regression | 相关 / 回归 | 是否一起变 / 变多少（预测） |
| t-test / ANOVA / chi-square | t 检验 / 方差分析 / 卡方 | 比较两组 / 多组平均数 / 类别变量关联 |
| Pearson r, r² | 皮尔逊相关系数、决定系数 | 关系强弱和方向；能解释多少差异 |
| Reject / fail to reject H₀ | 拒绝 / 不拒绝零假设 | 有变化要行动 / 证据不够照旧 |
