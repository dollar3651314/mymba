## 本节重点（中文讲解）

### 一、创业与创新
1. **创业的定义**：识别机会 → 抓住机会 → 利用机会（调动资金、人才等资源）建立企业。老师说这个定义来自熊彼特。
2. **创新的形式**（不一定要颠覆性）
   - 渐进式：洗衣机不断加温控、转速控制
   - 突破式：戴森无叶风扇
   - 组合式（设计思维）：把 AI 和洗衣机结合
   - 形态创新：洗衣凝珠（液体变成便携小包）
3. **创业者的特质**：敢冒风险、有愿景（比尔·盖茨预见每家都有电脑）、果断行动、沟通能力强（一分钟电梯演讲）、从问题中看到机会、会获取资源（如众筹）。还有**心理资本**（冒险、抗压、远见）和**社会资本**（人脉）。
4. **众筹（Kickstarter）**：设定目标金额和期限，**没达标就全部退款**。支持者其实是在“预购第一批产品”。
   - 反面案例：新加坡毕业生做的“全球最便宜便携打印机”两天筹到 300 万美元，但低估了生产成本，交不了货。教训：**众筹成功 ≠ 创业成功**。
5. **创造性破坏**：卡带 → CD → DVD → 流媒体；PC 整合音乐和电影，手机又整合了 PC。
6. **创业流程**：产生创意 → 评估 → 行动计划 → 获取资源（推销计划、融资、建组织）→ 启动。**不是线性的**，要用原型测试客户反馈并反复修改；服务类可以用“客户旅程图”。
7. **商业模式三要素**：价值主张（给客户什么独特价值）、价值架构（需要什么技术和活动来提供）、收入模式（订阅、按次付费、硬件销售、应用内购买）。苹果的软件服务收入已超过硬件；Airbnb、Uber/Grab、Google 都是**轻资产平台**。

### 二、8 个国际商务理论（A1 跨境转移部分的工具箱）

| 理论 | 一句话 | 适合用来解释 |
|---|---|---|
| 交易成本理论 | 企业跨国经营是为了降低搜寻、谈判、执行的成本 | 为什么外包或自己做 |
| 国际产品生命周期（Vernon） | 产品成熟、衰退后，生产转移到低成本国家 | 70 年代美国打印机、复印机转到海外生产 |
| 垄断优势理论 | 企业有技术、品牌、规模等优势，足以抵消海外风险 | 为什么敢出海 |
| 寡占反应理论 | 寡头行业里，一家出海，其他跟随 | 新航推出优选经济舱后别家跟进；车企扎堆墨西哥、东欧 |
| OLI 折衷范式（Dunning） | 所有权（O）+ 区位（L）+ 内部化（I）三个优势决定是否 FDI；不能内部化就用许可经营 | 选择进入模式 |
| Uppsala 渐进模型 | 国际化是渐进的，市场知识增加、心理距离缩短后才加大投入 | 先进入文化相近的市场 |
| 网络理论 | 企业国际化程度 × 市场国际化程度，分 4 种状态 | 靠伙伴网络出海 |
| 天生全球化 | 从成立第一天就面向全球（软件、数字银行、电商） | 数字化的创业企业 |

网络理论的 4 种状态（Johanson & Mattsson 的分类）：
- 企业低、市场低：早期起步者（纯本地公司）
- 企业高、市场低：孤独的国际化先锋
- 企业低、市场高：后来者
- 企业高、市场高：成熟的国际公司

## 案例练习（这就是学习日志要写的“tutorial 经历”）

**案例 1：家用户外披萨炉**
- 痛点：外卖披萨送到已经不新鲜；家里的电烤箱做不出柴火披萨的风味。目标客户是想在家吃美食级披萨的小众人群。
- 创新类型：**产品创新，但不是突破式创新**，是对户外烧烤和传统烤箱的改进替代。
- 商业模式：卖硬件 + 配套 App（食谱、社区）+ 病毒式传播（朋友来花园聚会看到就想买）。
- 推广：家庭活动路演、改装卡车做移动披萨厨房免费试吃；渠道是电商和沃尔玛等大型零售商。
- 局限：只适合有私人花园的家庭（美国、欧洲、澳洲），满足的是“想要”（wants），不是“需要”（needs）。亚洲市场难做。

**案例 2：在线日程预约工具**
- 解决的问题：减少来回发邮件约时间。用户分享链接或二维码，别人直接看空闲时间预约。
- 最大挑战：**获取用户**。先用免费基础版吸引大量用户，再靠高级功能订阅收费（freemium）。
- 推广难点：价值不直观，要清楚展示“减少邮件、节省时间”。

## 关键概念与术语

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| Opportunity recognition | 机会识别 | 发现未被满足的需求 |
| Incremental / radical innovation | 渐进式 / 突破式创新 | 小改进 / 根本改变 |
| Crowdfunding (all-or-nothing) | 众筹（全有或全无） | 没达标就退款 |
| Psychological / social capital | 心理资本 / 社会资本 | 抗压与远见 / 人脉网络 |
| Creative destruction | 创造性破坏 | 新技术取代旧模式 |
| Customer journey map | 客户旅程图 | 画出客户使用服务的每一步 |
| Value proposition | 价值主张 | 为客户提供的独特价值 |
| Asset-light platform | 轻资产平台 | 不拥有资产却连接供需（Airbnb） |
| Transaction cost theory | 交易成本理论 | 降低搜寻、谈判、执行成本 |
| International product life cycle | 国际产品生命周期 | 成熟期转移到低成本国家生产 |
| Monopolistic advantage | 垄断优势 | 技术、品牌等独特优势 |
| Oligopolistic reaction | 寡占反应 | 竞争对手出海就跟随 |
| Freemium | 免费增值模式 | 基础免费、高级收费 |
