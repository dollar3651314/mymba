## 本节重点（中文讲解）

1. **社会企业的定义（4:10–9:41）**：社会企业也可以赚钱、也可以有利润（例如用来发员工奖金、激励员工），区别在于**目标**是解决社会问题；它的利润主要用来服务社会使命，而不是回报股东。老师举的新加坡例子：**NTUC FairPrice**（合作社，购物积分回馈会员）、**Willing Hearts**（为有需要的人准备饭菜，老师自己去做过义工）、**Helping Hand**（中途之家）、小贩培训。
2. **为什么需要社会企业：社会问题越来越复杂（11:55–43:29）**
   - 贫困（几千年都没解决）；**没有厕所**——老师提到新加坡的**世界厕所组织**（约 25 年），在印度农村建厕所，但村民不用，因为“看不到价值”；女性夜里外出如厕不安全。
   - “**金字塔底层**”（Prahalad 2004）：世界上最大的人群在底层，企业以为他们没钱而不去服务，这其实是**市场机会**。
   - 安全饮用水、基本医疗（老师批评新加坡从邻国“挖”医生）、可负担住房（集装箱房屋）、垃圾填埋场（菲律宾的拾荒者）、森林砍伐、AI 和机器人带来的失业。
   - 市场靠价格和竞争运转，会带来剥削廉价劳动力和原材料；政府干预有时也无效 → **需要新的人、新的想法**。
   - **联合国可持续发展目标（SDGs）**：很多公司把其中两三个目标写进自己的目标；老师认为联合国没有对各国政府的管辖权，执行力弱。
   - 老师请大家说新加坡的社会问题：**收入不平等、人口老龄化**、心理健康、毒品等。
3. **社会创业与社会创新（46:07–55:47）**
   - 社会创业：发现社会问题，用创新方式（服务、产品或流程）解决，并建立能持续运营的商业模式。关键词：**最大化社会影响、带来改变**——“停止做了很多年都没用的事”。
   - 两条路：建立**社会企业**；或者用**社会创新**的新想法申请资金支持。社会企业要能自己赚钱，靠捐款不可持续。
   - 社会创新的三个条件：发现**被政府和市场忽视的需求**；建立新的合作关系；**赋权**（社会企业很难用高薪招人，要用别的方式吸引人）。
4. **设计思维（54:26–1:06:27）**：以用户为中心。先**同理**（站在用户角度了解需求）→ **定义问题** → **构思**（头脑风暴：用便利贴，所有想法都不评判，再分组归类、在别人的想法上继续发展；“如果你是乔布斯 / 马斯克会怎么做？”）→ **原型** → **测试**；还可以画**顾客旅程**（例如病人从急诊到出院后随访）。老师强调：**洞察**（insight）最重要，“没有对问题的洞察，就找不到对的解决方案”。
5. **系统思维：冰山模型（1:07:18–1:16:26）**：看得见的是**事件**，下面是**行为模式**、**结构**、**心智模式**。例子：“睡得少就容易生病”是模式；往下挖是压力大、没时间运动；再往下的心智模式是“健康饮食太贵”“休息是浪费时间”。老师说这种层层追问的方法**很适合做访谈**（你们的咨询项目要做一手调研的话可以用）。
6. **两段视频（1:16:26–1:29:05）**
   - **尤努斯和格莱珉银行**：70 年代孟加拉一个村子 42 个人只需要共 27 美元就能摆脱高利贷；小额无抵押贷款；2006 年获诺贝尔和平奖。
   - **TOMS 鞋“买一捐一”**：老师说后来“捐赠”比鞋本身更出名；TOMS 后来在当地设厂生产、创造就业。
7. **社会企业的七种创新方式（1:29:05–1:31:09）**：新产品 / 服务 / 想法；新流程或技术；把已有产品带到**未被服务的市场**；新的供应来源；重新设计组织结构；利用新的劳动力来源；**新的融资模式**。
8. **国际社会创业（1:31:09–1:32:30）**：走出本国就是“国际社会企业”，要理解当地情境；扩张太快会遇到理念不一致的合作伙伴——**伙伴要和你的使命一致**，否则为了低成本牺牲质量，最终失去信任。

## 分组练习：新加坡人口老龄化（1:32:30–结束）
- 题目：老人在家中独自离世，几天后才被发现——深层原因可能是**跌倒后无法求助**、**社会孤立**。
- 老师要求：先用**系统思维**找洞察，再用设计思维；建立**用户画像**（几岁、男还是女、和谁住、住几房的组屋、收入水平）。
- 各组想到的：家里装动作感应器（一两天没有动静就通知）、陪伴机器人等。老师的点评：**大家太快跳到解决方案**，要先把问题和用户定义清楚。

## 关键概念与术语
| 英文 | 中文 | 一句话解释 |
|---|---|---|
| Social enterprise | 社会企业 | 用商业方式解决社会问题，可以盈利 |
| Social innovation | 社会创新 | 新的、对社会有价值的解决办法 |
| Bottom of the pyramid | 金字塔底层 | 最大但最少被服务的人群 |
| Design thinking | 设计思维 | 同理 → 定义 → 构思 → 原型 → 测试 |
| Systems thinking / iceberg model | 系统思维 / 冰山模型 | 事件 → 模式 → 结构 → 心智模式 |
| Insight | 洞察 | 对问题真正原因的理解 |
| Persona | 用户画像 | 具体描述你服务的那个人 |
| Customer journey | 顾客旅程 | 顾客接触企业的每个环节 |
| Microfinance | 小额信贷 | 尤努斯、格莱珉银行 |
| One-for-one | 买一捐一 | TOMS 的模式 |
| Empowerment | 赋权 | 让人参与并有决定权 |
