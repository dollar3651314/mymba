## 本节重点（中文讲解）

**1. 走向海外要回答的问题（16:36–21:19）**
什么时候国际化？哪个市场增长潜力最大？用什么进入方式（下周讲）？产品、价格怎么调整（第 8 周讲营销）？**有没有内部能力建立并保持竞争优势**（今天讲）？

**2. 可持续的竞争优势 + VRIO（16:36–18:43）**
竞争优势可以来自技术、知识产权（专利）、人才团队、生产成本、扩张速度——关键是**能不能长期保持**。检验工具 **VRIO**：有价值吗（Valuable）？稀缺吗（Rare）？难模仿吗（Inimitable）？公司组织得好能利用吗（Organised）？全部通过才是可持续的优势。

**3. 三个理论（老师补充）（22:53–36:57）**
- **先行者优势**（市场增长快慢 × 技术变化快慢的 2×2 矩阵）：都慢 → 慢慢建品牌；都快（“激流”）→ 同时扩张市场和做研发；技术快市场慢 → 靠研发；市场快技术慢 → 压低单位成本、快速销售。先行者容易被记住（Uber、Sony Walkman）、先拿到合作伙伴。
- **Porter 一般竞争战略**：成本领先（Uniqlo）、差异化（LV、Muji 的环保天然材质）、成本集中（H&M 面向年轻人的快时尚）、差异化集中（Lululemon 起步于瑜伽小众市场、定价高）。
- **规模经济**：产量越大，固定成本摊得越薄，单位成本越低（例：一个教室 5 个学生和 20 个学生，固定成本一样）。

**4. 进入海外市场的方式（下周细讲）（37:07–40:08）**
直接出口（风险最小）→ 许可 → 特许经营 → **合资**（新成立一家公司；老师：**合资股权一定是 49 / 51，不能 50 / 50**，否则有争议时谁都做不了主）→ 并购 / 新建投资（这两种才是 FDI）。

**5. 团队和治理（40:08–54:05）**
- 创始人要有**全球视野、国际经验、主动、创新、敢冒险、文化敏感**；国际新创企业（INV）。
- 文化例子：中国饭局座位（主人、主宾位置）、日本人说 “yes” 不一定是同意（高语境文化）、在日本坐车的位置。
- **新、小、外来者的劣势**（liability of newness / smallness / foreignness）：新企业、小企业、外国企业失败的概率更高。
- 治理：总部统一**品牌和财务报告**，其他放权给当地团队；跨职能团队 + 当地专家。

**6. 融资（54:05–1:10:31）**
- **内部**：自己的钱（老师不建议）、亲友（会伤感情）、**留存收益**、卖资产。
- **外部**：银行贷款 / 透支（要抵押或个人担保；还不起会破产，几年内不能出国、不能当董事）。
- **自力更生（bootstrapping）**：先收客户的钱、跟供应商谈账期（如 60 天）、租而不买。
- **非传统**：**众筹**（Kickstarter 等；产品设计容易被抄）。
- 练习里的融资方式：银行（付利息、要抵押）、风险投资（要出让股权、可能派人进管理层）、**按收入分成融资**（投资人拿收入的 5% 直到收回 3 倍——收入不是利润，即使亏钱也要付，很危险）。
- 老师讲的学生创业例子：在理工学院食堂投标后转租给摊主、抽成；连锁发廊；美睫店。

## 关键概念与术语
| 英文 | 中文 | 一句话解释 |
|---|---|---|
| Sustainable competitive advantage | 可持续竞争优势 | 对手长期难以追上的优势 |
| VRIO | VRIO 分析 | 有价值、稀缺、难模仿、组织好 |
| First-mover advantage | 先行者优势 | 第一个进入市场带来的好处 |
| Porter's generic strategies | 波特一般竞争战略 | 成本领先、差异化、集中 |
| Economies of scale | 规模经济 | 产量越大单位成本越低 |
| International new venture (INV) | 国际新创企业 | 一成立就做国际业务 |
| Liability of newness / smallness / foreignness | 新 / 小 / 外来者劣势 | 新、小、外国企业更容易失败 |
| Joint venture (49/51) | 合资（49 / 51） | 双方成立新公司，股权不能对半 |
| Bootstrapping | 自力更生融资 | 用客户预付款、供应商账期等 |
