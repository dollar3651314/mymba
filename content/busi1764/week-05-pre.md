## 要点（中文讲解，按课件顺序）

### Mini-Lecture 5.1：可行性分析

**1. 什么是可行性分析（第 3–4 张）**
- 判断一个商业想法**是否可行（viable）**的过程；是对想法的**初步评估**，目的是决定这个想法值不值得继续做。
- 课件特别强调：**它不是商业计划书**（NOT A BUSINESS PLAN）。
- 什么时候做：在**刚开始考虑**一个新企业的时候，在投入资源**之前**筛选想法。

**2. 为什么重要（第 5 张）**
- 判断是否可行；避免浪费大量资源和时间；看清大局、提出重要问题；还可能带来新的机会或替代方案（想法在分析中被改得更好）。

**3. 四个阶段（第 6、7、21 张的图）**
```
提出的商业想法 → 值不值得投入时间和资源，取决于：
   ① 产品 / 服务可行性
   ② 行业 / 目标市场可行性
   ③ 组织可行性
   ④ 财务可行性
→ 四个方面都“是” → 继续，写商业计划书
→ 有一个或以上“否” → 放弃，或重新思考这个想法
```
最后还有一步“总体评估（Overall Assessment）”。

**4. ① 产品 / 服务可行性（第 8–9 张）**
- 两部分：**产品吸引力**（desirability：人们想不想要）和**产品需求**（demand：会不会真的买）。
- 评估需求的三步：
  1. **和潜在客户面对面交谈**
  2. **做问卷调查**
  3. **“侦探式调查”（Gumshoe research）**：讲者备注解释——像侦探一样到处找线索，通过和人交流、**观察**来判断需求。

**5. ② 行业 / 目标市场可行性（第 10–12 张）**
- **有吸引力的行业**的特点：年轻而不是老；处在生命周期早期；**分散**而不是集中（没有几家大公司垄断）；在增长而不是萎缩；卖的是客户“必须有”而不是“想要有”的东西（课件举例 FMCG 快消品）；不拥挤；经营利润率高；**不依赖某种原材料一直便宜**（如汽油、面粉）才能赚钱。
- **目标市场**：要**大到能养活这个新企业，又小到大公司看不上**。评估目标市场比评估整个行业更难，要动脑筋找信息。

**6. ③ 组织可行性（第 13–16 张）**
- **管理能力（Management prowess）**：最重要的两点——创业者 / 创始团队对这个想法的**热情**；他们**对目标市场的了解程度**。
- **资源充足性（Resource sufficiency）**：列出推进这个想法最关键的 **6–12 项非财务资源**；如果关键资源拿不到，这个想法可能就不现实。
- 非财务资源例子：负担得起的办公空间；实验室、生产或服务场地；能找到代工厂或服务商；关键管理人员和支持人员（现在和将来）；能不能拿到**知识产权保护**；能不能建立有利的**合作伙伴关系**。

**7. ④ 财务可行性（第 17–20 张）**
- **启动所需现金总额**：让企业做成第一笔生意之前需要的全部现金。要做一份**实际预算**，列出赚到“第一块钱”之前所有的资本购置和运营费用，看这个数是否现实。
- **类似企业的财务表现**：拿已经在经营的类似企业做比较来估算。方法：看行业报告（有免费的也有收费的）；做简单的**观察调查**——课件举例：New Venture Fitness Drinks 的创始人可以数一数类似餐厅的客流，再估计每位客人平均花多少钱，来推算销售额。课件说这需要一点“**合乎道德的**侦探工作”。
- **总体财务吸引力**——有前景的机会通常有这些财务特征：头 5–7 年在清晰的细分市场里销售稳定快速增长；**经常性收入**比例高（赢得一个客户后会反复带来收入）；收入和支出能比较有把握地预测；能用自己赚的钱支撑增长；投资人有**退出机会**（把股权变现）。

### Mini-Lecture 5.2：撰写商业计划书

**8. 什么是商业计划书、谁看（第 3–5 张）**
- 一份书面叙述，**通常 25–35 页**，说明新企业打算做成什么、怎么做到。
- **双重用途**：对内，让员工步调一致、朝同一方向前进；对外，向投资人和其他利益相关方证明这家企业值得投钱、值得关注。
- 要把企业所有重要方面讲清楚、讲简洁：长到信息充分，短到读者不会失去兴趣。

**9. 三种商业计划书（第 6 张）**
| 类型 | 篇幅 | 适合 |
|---|---|---|
| 摘要版 Summary | 10–15 页 | 早期阶段，想“试水”看投资人有没有兴趣 |
| 完整版 Full | 25–35 页 | 需要融资的阶段；也是企业运营的“蓝图” |
| 运营版 Operational | 40–100 页 | 主要给内部看，指导运营经理 |

**10. 写的时候要知道：计划会变（第 7 张）**
- 写的过程中、听到别人反馈后，总会有新的想法，所以计划在写的时候就会改。

**11. 商业计划书的 11 个部分（第 8–19 张）**
| 部分 | 要写什么 |
|---|---|
| 执行摘要 Executive summary | 整份计划的简短概述，不超过 2 页单倍行距；**放在最前面，但最后写** |
| 行业分析 Industry analysis | 行业规模、增长率、销售预测；行业结构；参与者；关键成功因素；趋势；长期前景 |
| 公司描述 Company description | 公司简介和历史；**使命陈述**；产品和服务；现状；法律形式和所有权；主要合作伙伴 |
| 市场分析 Market analysis | 把行业**细分**，选定目标市场；购买行为；**竞争对手分析**；估计年销售额和市场份额 |
| 企业经济学 Economics of the business | 怎么赚钱：收入驱动因素和利润率；固定成本和变动成本；经营杠杆；启动成本；**盈亏平衡**图和计算 |
| 营销计划 Marketing plan | 总体营销战略；产品、价格、促销、渠道（4P）；销售流程；销售策略 |
| 产品 / 服务设计与开发计划 | 开发进度和任务；挑战和风险；开发成本；**专有权问题**（专利、商标、版权、许可、品牌名） |
| 运营计划 Operations plan | 企业怎么运转：用“**后台**”（客户看不到）和“**前台**”（客户看得到）的活动来描述；地点；设施和设备 |
| 管理团队和公司结构 | 管理团队；董事会和顾问委员会（如有）；公司结构 |
| 总体时间表 Overall schedule | 用**里程碑**列出启动企业的大事：注册公司、完成原型、租场地、拿到关键融资、开始生产、**拿到第一笔订单** |
| 财务预测 Financial projections | 资金来源和用途表；假设表；预测利润表、资产负债表、现金流量表；比率分析 |

**12. 向投资人展示（第 20–21 张）**
- 口头展示第一条规矩：**按要求来**，给 20 分钟就别超时；要流畅、排练过；幻灯片清楚不杂乱；预先想好投资人会问什么。
- 投资人展示的 **12 张幻灯片**：标题页 → 问题 → 解决方案 → 机会和目标市场 → 技术 → 竞争 → 营销和销售 → 管理团队 → 财务预测 → 现状 → 需要的融资 → 总结。

## 案例摘要

**Keurig Kold 苏打水机（Soda Machine Case）→ Tutorial 第一部分**
Keurig 的胶囊咖啡机很成功（约 17% 美国家庭有），2015 年照搬模式推出在家做苏打水的 Kold，期望它卖得比咖啡机还好，结果 **9 个月就下架**。案例列了 5 个原因：① 太贵（机器 369 美元，最便宜的 SodaStream 79 美元；每杯 8 盎司约 50 美分，而超市品牌汽水每 12 盎司约 37.5 美分）；② 太大、太吵、要插电；③ 胶囊只有一种 8 盎司规格；④ 美国人出于健康原因正在少喝汽水；⑤ **没人在家“做”汽水**——咖啡本来就在家煮，Kold 却要人改变习惯。案例结论：可行性分析必须在上市**之前**做，而且四个方面都重要。

**Beyond Meat（Be the VC Startups + Beyond Meat Introduction）→ Be the VC**
想法：用植物蛋白做出口感、味道都像肉的“肉”。推介说：很多人因为健康、动物福利、温室气体排放想少吃肉，但豆腐、素肉饼口感差，吃一阵又回去吃肉。产品出自密苏里大学两位科学家 15 年以上的研究，第一款是无鸡肉鸡条，先在 Whole Foods 这类健康食品店卖。另一份 PDF 是公司的**投资人路演 PPT**，用大量消费者调查数据（如“70% 吃肉的人每周至少有一餐用非肉蛋白替代”）、核心目标客户“矛盾的肉食者”（Conflicted Carnivores）、和快餐连锁合作、运动员代言来证明市场——可以当作“**怎么用数据说服投资人**”的范例看。

**Go-Jek（Be the VC Startups）→ Be the VC**
2010 年在印尼成立的摩托车网约车（ojek）App。雅加达等城市堵车严重，摩托车最快，但传统摩的不安全、无监管、不卫生；Go-Jek 用实时追踪、免费头套和口罩解决这些问题，并扩展到 25 个以上城市、物流、送餐等服务。司机叫“合作伙伴”而不是员工，但有保险和福利。用推荐码奖励（新老用户各得 2 美元）推动口碑传播。

**Rent the Runway（小组任务二选一）**
两位哈佛 MBA 同学 2008 年想到：女性每年有很多需要盛装的场合，**为什么不租而要买**？她们先找设计师验证供给方——Diane von Furstenberg 不喜欢“省钱”的说法，但让她们发现设计师品牌缺年轻客户和小城市客户，于是**把定位从“省钱”改成“把年轻女性带给设计师”**。再做了 3 次客户测试（哈佛试穿、耶鲁只看不试、发 PDF 给 1,000–2,000 人），发现她们卖的其实是“自信和难忘的时刻”。2009 年 11 月上线，两周 10 万会员。**这是“可行性分析把想法改得更好”的正面案例。** 问题 3-34～3-37：列出她们上线前验证想法的方法、从想法到上线隔了多久、没做可行性分析会怎样、你的启示。

**Embrace Infant Warmer（小组任务二选一）**
斯坦福“极致可负担设计”课的学生项目：发展中国家每年约 1,500 万早产和低体重婴儿，最大死因是失温；医院保温箱约 2 万美元、要持续供电。团队去尼泊尔实地看后发现，约 80% 早产儿生在**农村**，根本到不了医院——于是放弃“做便宜保温箱”，改做像小睡袋、充电 30 分钟能保温最多 6 小时的便携保暖袋。在印度农村反复测试（妈妈们会把温度调低“以防万一”→ 改成预设温度 + OK/Not OK 开关；村民想要租用选项；婆婆常是决策人），**60 多次迭代**后 2011 年上市。非营利 + 营利两条线，后来推出美国零售品牌 Little Lotus，买一件就为有需要的妈妈捐一部分钱。问题 3-38～3-41：目标市场及吸引力、做了哪些一手调查、怎样收集客户反馈、财务可行性要考虑什么。

**Birchbox（课件里没有提到）**
两位哈佛 MBA 同学做的美妆小样订阅盒（每月 5 个小样，再卖正装）。她们让每门课的期末作业都做 Birchbox，用学生身份联系品牌（Benefit、Nars、Kiehl's 签约），用 200 个付费测试用户改进产品，参加商学院**商业计划书比赛**拿第二名并认识了导师。2010 年上线，后来增长快但不赚钱，2016 年裁员、融资、调整商业计划（开实体店、做自有品牌），竞争对手 Ipsy 很强。⚠️ Tutorial 课件里没有提到这个案例，它和 Be the VC 一起放在 Tutorial Resources 文件夹里，可能是补充阅读——课上看老师用不用。**对你有用的一点**：她们把课程作业当成创业练习，和你的 A2 很像。

## 这节课和作业的关系

### A2 个人报告：可行性分析和商业计划书怎么对应报告各节
> 这是帮你看懂的线索，要用你自己的分析和语言写。

| A2 报告部分（brief 的问题） | 本周能用的内容 | 怎么用（线索） |
|---|---|---|
| 1 商业想法：卖什么？客户为什么买？ | ① 产品吸引力和需求；计划书的“公司描述”（使命陈述、产品和服务、法律形式和所有权） | 开头用一两句使命陈述把目标说清楚（评分“商业想法”20% 看的就是目标清晰、全文聚焦）；说明客户“为什么买”时，用你调查到的需求证据，而不是只说“我觉得” |
| 2 机会识别：怎么发现需求、怎么抓住 | ① 需求三步（面谈、问卷、侦探式调查）；② 行业吸引力 8 条特征、目标市场“大到能养活、小到大公司看不上” | 你自己做的小规模访谈或问卷就是一手证据（评分“证据”20%）；用行业数据说明这个行业在增长、不太集中；可以做一张“行业吸引力”打勾表当作图表 |
| 3 社区影响 | 计划书“公司描述”里的使命陈述；Embrace 的非营利 + 营利双线、Little Lotus 买一捐一 | 本周不是重点，但 Embrace 是“商业 + 社会影响”的例子，可以配合第 4 周社会创业的内容 |
| 4 资源与网络：资源稀缺怎么克服 | ③ 组织可行性：管理能力（热情、懂市场）、**列 6–12 项关键非财务资源**（场地、代工、人员、知识产权、合作伙伴） | 列出你这个想法最缺的几项资源，再逐项说明通过谁（网络关系、伙伴）拿到——这样第 4 节就有具体内容，并能连到第 8 次课的网络理论 |
| 5 融资 | ④ 财务可行性：启动现金预算（赚到第一块钱前的所有支出）、类似企业的表现、有前景机会的财务特征（经常性收入、可预测、退出机会）；计划书的“资金来源和用途” | 先算出大概要多少启动资金，再说用什么方式融资；好范例 2（Eco Fibre Wear）就有一张 £70,000 启动成本表——一张“资金来源和用途”小表就是很好的图表 |
| 6 知识产权 | 组织可行性里的“能否获得知识产权保护”；计划书“产品开发计划”里的专有权问题（专利、商标、版权、许可、品牌名） | 判断你的想法里哪一样最需要保护，第 11 次课再展开 |
| 7 国际化：市场、竞争对手、细分、推广 | 计划书的“行业分析”“市场分析”（细分 → 选目标市场 → 购买行为 → 竞争对手分析）和“营销计划”（4P、销售流程）；Go-Jek 只在印尼、对手更国际化的问题 | 进入新国家时，对目标国家再做一次简短的行业 / 市场分析；竞争对手比较表正好用上 |
| 8 反思（30%） | Keurig Kold 的教训；Rent the Runway 和 Embrace 怎样因为反馈改想法；“计划在写的时候会变” | 把**你自己的想法在筛选、调查中怎么改变**记下来，这是最真实的反思素材；今晚 Be the VC 你给了几分、为什么，课后马上记下来 |

**要注意的两点**
1. **A2 不是一份完整的商业计划书**。完整版要 25–35 页，A2 只有 2,000 字，而且必须按 brief 的 7 个问题 + 反思来写。用本周的框架做**思考和检查的工具**，不要照搬 11 个部分的结构。
2. 执行摘要“放最前、最后写”的道理同样适用：A2 的引言最后写。

### 10/23 前：用可行性分析筛选你的 2–3 个想法
每个想法逐条回答，答不上来的就是还要查的地方。答案用中文写几句就行，10/23 一起发给 Claude。

**A2 的硬性条件（不满足就直接换）**
- [ ] 是我自己的初创想法，或者是一家**小型** SME / 家族企业的新产品或新服务（不是大公司）
- [ ] 不是 tutorial 小组讨论过的想法（老师还没确认这条，先避开）
- [ ] 有机会**拓展到海外**（A2 第 7 节要写进入哪些国家）
- [ ] 能讲出对**当地社区**有什么帮助（第 3 节）

**① 产品 / 服务：有没有人要？**
- [ ] 一句话说清楚：卖什么、卖给谁、解决什么问题
- [ ] 我能在 11 月前找到 5 个左右潜在客户聊一聊，或者做个小问卷吗？
- [ ] 有没有能观察到的需求线索（排队、抱怨、网上评论、类似店铺的客流）？

**② 行业 / 目标市场：这个市场好不好？**
- [ ] 行业在增长吗？能找到可靠的市场规模或增长数据吗（报告、政府统计）？
- [ ] 行业是分散的，还是被几家大公司占着？
- [ ] 目标客户群具体是谁？规模够我活下去、但大公司又看不上吗？

**③ 组织：我做得了吗？**
- [ ] 我对这个想法有热情吗？我了解这个市场吗（工作、家庭、生活经历）？
- [ ] 最关键的几项非财务资源是什么（场地、供应商、人、知识产权、伙伴）？我能通过身边的网络拿到吗？

**④ 财务：钱上说得通吗？**
- [ ] 做成第一笔生意前大概要花多少钱？量级合理吗？
- [ ] 怎么赚钱？有没有回头客或订阅这样的经常性收入？
- [ ] 能找到类似企业做比较吗？

**写报告够不够料（A2 特有）**
- [ ] 每一节（机会、资源、融资、知识产权、国际化）都有东西可写吗？
- [ ] 这个想法能让我写出真实的反思吗？

> 四个方面都基本“是”的想法优先；有一个“否”的，想想能不能改（像 Rent the Runway 那样改定位），不能改就换。
