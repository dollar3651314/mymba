## 本节重点（中文讲解）

**1. 这节课和前面的连接（3:46–5:57）**
第 4 次课：在新加坡找一个社会问题 → 想出社会创新方案、做商业模式 → 第 5 次课做可行性分析、商业计划书 → **今天：把这个项目推向海外，选市场、选进入方式**。商业计划书里本来就应该有国际化 / 市场进入这一部分。

**2. 选市场：PESTEL（老师叫它 “PESTLE”）（7:19–51:17）**
- **政治**：现在的政府政策、法规；接下来的变化（例如选举）。
- **经济**：GDP 增长、**通胀**、利率、汇率、失业率。老师：高通胀 + 高失业往往导致政府下台；可以接受的通胀大约 2%–4%；通胀高 → 工资要涨、利率要高、消费需求下降。
- **数据去哪找**：**IMF、世界银行类数据库、CIA World Factbook**（可以两国对比、做图表），要注明数据来源（20:33–25:20）。
- **社会**：生活方式（社交媒体、独居、独自旅行）、人口结构（年龄分布：新加坡老龄化 vs 印度、菲律宾年轻）、代际（婴儿潮、X、Y、Z 世代；Z 世代想远程办公 → 影响办公空间需求）。
- **技术**：技术普及程度、竞争对手研发投入、自助服务（扫码点餐）、区块链溯源。
- **法律**：个人数据保护（新加坡 PDPA）、外籍员工配额、合规成本（例子：新加坡私立学校从三四千所减到几百所，主要因为合规成本高；消防规定等）。法规变化 → 成本上升 → 要改流程。
- **环境**：欧盟可持续报告要求（ESRS）、碳信用、废物处理（电池）、包装（可降解 / 可回收材料更贵）。

**3. 之后怎么分析（51:17–55:55）**
PESTEL 找出的因素 → 放进 **SWOT**（优势、劣势、机会、威胁）→ 再做 **TOWS**：用优势抓机会、用优势挡威胁、补劣势……把分析变成**行动**。老师强调：课件没讲 SWOT 之后做什么，但要做这一步。

**4. 行业分析：波特五力（55:55–1:02:39）**
PESTEL 看**宏观**市场，五力看**行业**（微观）：买方议价能力、供应商议价能力、新进入者威胁、替代品威胁、行业竞争程度。每一项要打分（强 / 中 / 弱）。例子：液晶屏供应商很少（三星、LG、京东方、TCL），供应商议价能力强。

**5. 进入模式（1:02:39 起）**
| 模式 | 老师的要点 |
|---|---|
| **出口** | 最早、最省钱的方式；风险：认证（食品、电器要认证）、付款风险 → 付款方式：预付、货到付款、**信用证（LC，很贵）**、赊账（要有信任）；FOB 等贸易条款 |
| **许可（licensing）** | 允许别人用你的技术或品牌，收许可费；好处：不用投资就能快速进入新市场；坏处：**失去控制**、品牌可能被滥用（例：日本老牌子被授权做电饭煲、扫地机器人）、**伙伴可能变成竞争对手** |
| **特许经营（franchising）** | 加盟商用你的品牌和整套运营系统（例：7-Eleven、餐饮）；好处：成本低、用当地人的本地知识；坏处：**质量控制难**（加盟商改配方）、各地法律不同、文化差异；例：星巴克靠标准化（同样的装修、音乐、沙发）控制品质 |
| **合资（joint venture）** | A 公司 + B 公司成立新公司 C，各出资金、技术或市场渠道；要事先定好**退出和争议怎么解决**，通常 **51/49**，让一方有最终决定权；风险：文化冲突、分歧 |
| **全资子公司（含新建投资）** | 控制最强，但**最贵、风险最高**：没有本地伙伴和本地信息，要自己做市场调研 |
