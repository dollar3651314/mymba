请帮我从学校的 Moodle（moodlecurrent.gre.ac.uk）下载课程资料，继续用上次的文件夹 `~/Downloads/MBA资料`，并更新里面的 `进度清单.md`（✅ 已下载 / ⏳ 还没下载 / ❌ 找不到）。

**规则（一定遵守）**
- 只浏览和下载。不要提交任何作业，不要点 "Attempt quiz"，不要接受 Turnitin 用户协议，不要在讨论区发帖，不要修改任何设置。
- 遇到登录页、验证码或双重验证就停下来叫我。
- 已经下载过的文件不要重复下载（上次的文件都还在，先核对 `进度清单.md`）。
- 视频不用下载，只把标题和链接记进该课程的 `视频链接.txt`（追加，不要覆盖）。
- 网页里的链接（YouTube、HBR、Forbes、McKinsey 等）不用下载，记进 `补充阅读链接.txt`，注明第几周、必读还是推荐。
- 如果某一周的资料**老师还没发布**（看不到或显示隐藏），在 `没找到.txt` 里写“第 X 周：Moodle 上还没发布（检查日期 10/x）”，不要到处找。
- 每下载完一门课，把这门课的新文件夹单独压缩成 `课程代码_第X周.zip`（只放新下载的文件），然后告诉我，再做下一门。
- 中途页面崩溃或断开，重新打开后先看 `进度清单.md`，从没完成的地方继续。
